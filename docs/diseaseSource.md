# 落藏

落藏是周嘉荣老师发明的理论，其基于中医古藉《内经》中的记载，归纳总结出了一套万病落于藏的诊疗方法，经其数十年中医治疗实战经验，百试百灵。<br>
落藏理论的核心思想是，万病皆源于藏。病的表相千变万化，无法枚举，但无论哪种病的表现形式，其核心都是因为内部脏器的功能减弱或失调了，才导致相应的病产生，或导致相应的邪入侵。面对无以计数的种种病情，我们必须认清是哪个内部脏器病了，才能进一步确立治疗方案。所以中医望闻问切，望居首位，说的就是有能力的医生能够一望便知病在哪个脏器。<br>
落藏的藏，指的是脏腑系统，如肺藏，则是指肺、大肠，以及肺经、大肠经等共同组成的一个系统，其中肺主阴，大肠主阳，是密不可分的一个整体。<br>
<br>
看病的第一件事，就是要看病在哪里，一看经络走向，二看脏腑功能。<br>
一看经络走向。除了头面部，身体的其它地方，有清晰经络路线的，就大致是该经络脏腑的问题；<br>
二看脏腑功能。对于没有清晰经络路线的，就通过落藏来确定病源。比如浑身痒、掉眩、神志不清、肿、骨蒸、潮热、自汗、盗汗、不出汗、难受、暴躁不安、浑身发热等等，还有比如皮、肉、筋、骨等。<br>
三头面部要结合看经络和脏腑功能。头面部经络复杂，各经络穿插交错，往往不知道应该落在哪个脏上，这时就需要通过脏腑功能落藏，比如五官落脏、面部五区落脏、舌五区落脏，比如耳朵的问题，中耳炎、耳鸣、耳聋、耳背，因为耳兼心肾，所以要治心和肾，而不是治少阳。<br>
落了藏以后，就知道是谁病了，再来确定治谁。肯定不是哪病治哪。那么治哪里呐？这就要用到五行理论了。<br><br>

# 落藏的规则

## 肺（大肠）

- 肺主皮毛，肺其华在毛
- 肺主治节，病发背部
- 肺开窍于鼻
- 心肺有邪沉于两肘
- 久卧伤气劳于肺
- 诸气愤郁皆属于肺
- 肺通调水道
- 行寒饮冷伤肺
- 肺主忧，忧伤肺，喜胜忧
- 肺藏气，气舍魄，魄聚则为精
- 肺气虚则鼻塞不利少气
- 肺气实则喘厄胸盈仰吸
- 在变动为咳
- 辛味、辣味入肺
- 白色入肺
- 肺属金，气味为金属腥味
- 肺数为9
- 肺声为“呬”
- 其畜马，其谷稻，其果梨
- 肺主秋，肺主西方，肺主燥
- 肺的时辰为晨3点至5点
- 大肠的时辰为晨5点至7点

## 脾（胃）

- 脾主肌肉，病发肌肉
- 脾主四肢
- 脾开窍于口，脾其华在唇
- 久坐伤肉劳于脾
- 脾上有邪沉于两胯
- 诸病项强皆属于湿，诸湿肿满皆属于脾
- 脾主意，脾主思
- 思伤脾，怒胜思
- 湿伤肉，风胜湿
- 甘伤肉，酸胜甘
- 在变动为哕
- 脾气虚则四肢不用五脏不安
- 脾气实则腹胀经溲不利
- 甘味、甜味入脾
- 黄色入脾
- 脾属土，气味为香味
- 脾数为5
- 脾声为“呼”
- 其畜牛，其谷稷，其果枣
- 脾主长夏，脾主中土，脾主湿
- 脾的时辰为上午9点至11点
- 胃的时辰为上午7点至9点

## 心（小肠）

- 心开窍于舌，舌为心之苗
- 心开窍于耳，耳兼心肾
- 心开窍于目，久视伤血劳于心
- 心主血脉，病及五脏
- 心主神志
- 心主汗，汗血同源
- 心其华在面
- 诸痛痒疮皆源于心
- 心主喜，喜伤心，恐胜喜
- 在变动为忧
- 心藏脉，脉舍神
- 心气虚则悲
- 心气实则笑不休
- 苦味入心
- 红色入心
- 心属火，气味为焦味
- 心数为7
- 心声为“嚯”
- 其畜羊，其谷黍，其果杏
- 心主夏，心主南方，心主热
- 心的时辰为上午11点至下午1点
- 小肠的时辰为下午1点至3点

## 肝（胆）

- 肝开窍于目
- 肝其华在爪甲
- 肝主筋，病发惊骇
- 肝上有邪沉于两腋
- 久行伤筋劳于肝
- 诸风掉眩皆属于肝
- 女子以肝为本
- 肝主语
- 肝主怒，怒伤肝，悲胜怒
- 风伤筋，燥胜风
- 在变动为握
- 肝藏血，血舍魂，魂聚则为神
- 肝气虚则恐
- 肝气实则怒
- 酸味入肝
- 青色入肝
- 肝属木，气味为草食动物的臊味
- 肝数为8
- 肝声为“嘘”
- 其畜鸡，其谷麦，其果李
- 肝主春，肝主东方，肝主风
- 肝的时辰为凌晨1点至3点
- 胆的时辰为半夜11点至凌晨1点

## 肾（膀胱）

- 肾主脑（肾主髓，脑为髓之海）
- 肾主骨，病发关节
- 久立伤骨劳于肾
- 肾开窍于耳
- 肾开窍于二阴
- 肾其华在发
- 肾上有邪沉于两腘
- 肾为胃之关
- 诸寒收引皆属于肾
- 强力举重久坐湿地伤肾
- 恐伤肾，思胜恐
- 房事伤肾
- 在变动为栗
- 肾藏精，精舍志
- 肾气虚则厥
- 肾气实则胀，五脏不安
- 咸味入肾
- 黑色入肾
- 肾属水，气味为腐臭味
- 肾数为6
- 肾声为“吹”
- 其畜猪，其谷豆，其果为坚果
- 肾主冬，肾主北方，肾主寒
- 肾的时辰为下午5点至7点
- 膀胱的时辰为下午3点至5点
